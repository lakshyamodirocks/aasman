Aasmaan आसमान

Free AI on your own device — phone or PC. One Python file you can read. No account. No server of ours. Your data stays with you.

Built for the next billion: works on an ₹8,000 Android, in Hinglish, on 1 GB/month, for someone who has never typed to an AI. Adapts to your hardware; never depends on it.

Install — one command, three devices

Android · Termux

Install Termux from F-Droid (not Play Store), open it, paste:

pkg install -y curl python && curl -fsSL https://raw.githubusercontent.com/lakshyamodirocks/aasman/main/install.sh | bash

Linux · macOS · WSL2

Needs python3 and curl.

curl -fsSL https://raw.githubusercontent.com/lakshyamodirocks/aasman/main/install.sh | bash

Windows 10/11

PowerShell, normal user, no admin.

irm https://raw.githubusercontent.com/lakshyamodirocks/aasman/main/install.ps1 | iex

Every installer is staged: it shows your machine first, then asks before each step. Enter = do it · s = skip · q = stop (done stays done). Nothing installs silently. Python and Ollama are installed by you from their official installers; the script only prints the command.

What it does

Talks, offline first

A local model through Ollama, sized to your RAM/GPU. Free cloud tiers only if you add a key. If nothing is available it says so; it never fakes an answer.

18 experts with a base

Coding, writing, research-verify, video, voice, marketing, SEO, analytics, planning, finance (explain-only), coaching… each with a persona, refusals, a cheat-sheet and dated sources. /agent auto <task> picks.

Files and screenshots

/attach error.log, /attach shot.png — with a preview of what the model will see, and which brains can see images.

Knows itself

/capabilities reports what this install can do right now. "update yourself", "agents dikhao", "go offline" work as plain words — by rules, not by the model.

Updates you press

A one-line notice when a new version exists. ai update reinstalls; keys and memory are always kept. Never automatic.

Phone ↔ computer, by QR

ai pair on your Mac/PC prints a QR; your phone — iPhone too — scans it and uses that computer's ai over your own Wi-Fi or Tailscale. Token-locked. No server of ours.

Memory that is yours

Plain files in ~/ai-vault. Search them offline. Nothing is uploaded to anyone.

What it touches, what it never does

Writesits own folder, ~/.ai-* files, ~/ai-vault. On Windows, one folder in your user PATH only if you press Enter. Everything is listed in a manifest; uninstall removes exactly that list and leaves your keys and memory.
Sendsonly what you typed or attached, to your local Ollama, a provider you keyed, or a keyless endpoint you invoked. Cloud-bound text is scrubbed of emails, phones, IDs, keys, private IPs and names you list.
Neversudo/admin · pip install · editing .bashrc/.zshrc · touching your Ollama models · telemetry · a server of ours · acting unattended (the daemon can look, not act).

Honest limits

A 7B–14B local model writes functions, fixes tracebacks, explains algorithms. It does not refactor whole repositories; that is Claude Code / Codex territory. On a phone a 4B model is a helper, not a coder. Windows is verified by CI, not yet on a physical machine. iOS is a thin-client path. See ROADMAP.
